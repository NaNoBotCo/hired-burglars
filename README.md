# Hired Burglars · ขโมยรับจ้าง

Security work as toys, in English and Thai.
https://nanobotco.github.io/hired-burglars/

`page.html` is the page body (also the private artifact https://claude.ai/artifact/7PkMcf8NdCC3WNHqCUgEvB).
`python3 tools/build.py` wraps it into `docs/index.html`; `tools/card.py` draws `docs/card.jpg`;
`tools/serve.py` serves the folder on port 8884.
